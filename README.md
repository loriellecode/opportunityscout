# Opportunity Scout

Personal opportunity-discovery app (iPad-first). Finds real, verified film, education and work opportunities and lets you filter by format and location.

- `index.html`, `styles.css`, `app.js`: the app (reads opportunities from the Artifact database).
- `data/`: the collected opportunity and source records (JSON) that were loaded into the database.
- `img/`: free-licensed photos. Each opportunity record stores the photographer, license and source page.

Published app: https://claude.ai/artifact/8YBAkqYBdQnoF3ZvwDqQLt (private to the owner).
